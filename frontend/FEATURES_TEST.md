# 子計畫刪除功能測試指南

## 功能概述
已成功實現子計畫刪除功能，包含以下特性：

### ✅ 已完成的功能

#### 1. 刪除按鈕
- 每個子計畫項目右側都有垃圾桶圖標的刪除按鈕
- 按鈕會根據是否有參與者來改變狀態

#### 2. 參與者檢查邏輯
- 如果子計畫下有參與者：
  - 刪除按鈕變為灰色且無法點擊
  - 點擊時顯示 Toast 錯誤提示：「無法刪除，已有參與者正在此子計畫中。」

#### 3. 安全刪除流程
- 如果子計畫下沒有參與者：
  - 點擊刪除按鈕彈出確認 Modal
  - Modal 標題：「刪除子計畫」
  - Modal 內容：「確定要刪除「[子計畫名稱]」子計畫嗎？此操作無法復原。」
  - 提供「取消」和「確認刪除」兩個選項

#### 4. 用戶體驗優化
- 使用 Toast 提示替代 alert()，提供更好的用戶體驗
- Toast 自動在 3 秒後消失，也可手動關閉
- 成功刪除後顯示綠色成功提示
- 錯誤情況顯示紅色錯誤提示
- Toast 有滑入動畫效果

## 測試步驟

### 測試場景 1：刪除有參與者的子計畫
1. 進入「計畫管理」頁面
2. 找到有參與者的子計畫（參與者數量 > 0）
3. 點擊該子計畫的刪除按鈕（垃圾桶圖標）
4. **預期結果**：顯示紅色 Toast 提示「無法刪除，已有參與者正在此子計畫中。」

### 測試場景 2：刪除沒有參與者的子計畫
1. 進入「計畫管理」頁面
2. 新增一個子計畫（確保沒有參與者）
3. 點擊該子計畫的刪除按鈕
4. **預期結果**：彈出確認 Modal
5. 點擊「確認刪除」
6. **預期結果**：
   - 子計畫被成功刪除
   - 顯示綠色 Toast 提示「子計畫「[名稱]」已成功刪除」
   - 如果該子計畫在右側詳情區域被選中，右側區域會清空

### 測試場景 3：取消刪除操作
1. 對無參與者的子計畫點擊刪除按鈕
2. 在確認 Modal 中點擊「取消」
3. **預期結果**：Modal 關閉，子計畫不被刪除
